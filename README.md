# CryptoSpace

Багатомовний вебсайт сервісу обміну криптовалют (**UA / RU / EN**) із калькулятором обміну, вибором мережі переказу, автоматичною видачею реквізитів за заявкою та збереженням активної заявки на 24 години.

## Основні можливості

- **3 мовні версії:** українська (`/`), російська (`/ru/`), англійська (`/en/`).
- **Підтримувані активи та мережі:**
  - **USDT:** TON (Jetton), TRON (TRC20), Solana (SPL), Ethereum (ERC20), BNB Smart Chain (BEP20)
  - **USDC:** Ethereum (ERC20), Solana (SPL), BNB Smart Chain (BEP20)
  - **Нативні мережі:** BTC (Bitcoin), ETH (Ethereum), SOL (Solana), TRX (TRON), LTC (Litecoin), DOGE (Dogecoin)
  - **Фіатні напрямки:** Готівка USD, Готівка UAH, Картка UAH
- **Точна десяткова арифметика:** розрахунок сум без похибок плаваючої коми з урахуванням точності кожної валюти.
- **Форматування номера телефону (`+380`):** підтримка вводу, вставки у форматах `0671234567` / `+380671234567`, редагування та валідації коду оператора.
- **Фіксація заявки:** генерація унікального номера заявки, реквізитів гаманця для обраної мережі та збереження активної заявки у браузері на 24 години.
